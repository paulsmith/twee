# tree: review a release package

- **App:** tree (run from Bash)
- **Persona:** Elena, a release coordinator checking that a handoff package has the expected services and documentation.
- **Mission:** Inspect the release layout, hide generated clutter, and focus on the Markdown documents that need review.
- **Journey:** Print the hierarchy while excluding generated paths, then filter and prune to the reviewable Markdown files.
- **Value demonstrated:** Useful exclusion, filtering, and pruning options applied to a concrete release-readiness task in a real shell session.

# Claude Code — release-risk briefing

**App:** Claude Code CLI.

**Persona:** A release manager preparing a concise go/no-go briefing.

**Mission:** Review a tiny release-notes fixture and identify the three risks that need an owner before launch.

**Journey:** Open an isolated temporary project, submit a read-only request at human typing speed, let Claude inspect only `brief.txt`, then read the concise risk recommendations and exit.

**Value demonstrated:** Claude turns a focused operational note into a structured release conversation while session persistence, browser integration, and file edits are disabled.

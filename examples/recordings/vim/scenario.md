# Vim: prepare a deployment handoff

- **App:** Vim
- **Persona:** Mina, an on-call release engineer handing a planned API deployment to the next shift.
- **Mission:** Update the incident handoff checklist with the rollback owner and the required database snapshot, then mark the error-budget review as complete.
- **Journey:** Open the existing checklist, add two concrete follow-up items, search for the error-budget item, annotate it as reviewed, save, and quit.
- **Value demonstrated:** A deliberate, readable edit flow through normal, insert, search, and command-line modes that leaves a useful saved artifact.

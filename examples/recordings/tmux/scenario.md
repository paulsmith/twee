# tmux incident handoff

- **App:** tmux
- **Persona:** Maya, the on-call engineer taking over a production incident.
- **Mission:** Keep the API symptoms and response actions visible side by side while preparing a concise handoff.
- **Journey:** Maya opens an incident session, records the API alert in the first pane, splits it for queue status and ownership, then closes both panes after the handoff notes are complete.
- **Value demonstrated:** tmux keeps related operational context in independently focused panes without losing the shell workflow.
